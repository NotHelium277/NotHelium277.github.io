# Md Hasib Mozumder portfolio

A responsive three-page portfolio built with React, Vite, React Router, and Framer Motion. The laptop and its dashboard scenes are rendered with HTML and CSS; no laptop stock image is used.

## Run locally

1. Install Node.js.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and replace the sample email with the address that should receive enquiries.
4. Run `npm run dev`.

The contact form validates required fields and opens a prefilled message in the visitor’s email app. For direct submission without an email client, connect a form endpoint or backend.

## Personalize before publishing

- Review the sample positioning and update it to match your experience and services.
- Add verified biography, dates, project outcomes, and links. The About page deliberately contains an editable note instead of invented experience.
- Set `VITE_CONTACT_EMAIL` to a monitored address.
- Review page titles and metadata in `index.html` for the final brand.
